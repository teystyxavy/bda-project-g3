# Command-driven ingestion infrastructure

**1 November 2026 deployment verified:** baseline verification,
rule scoring and dashboard export now use Glue jobs `is459-g3-ingest-baseline`
and `is459-g3-ingest-export`. SageMaker is used only for optional candidate
training. The fresh 1,000-row AWS smoke passed through public publication with
all four Glue jobs successful. Earlier acceptance records below describe the predecessor.
See [migration and validation](../../planning/runbooks/glue-stage-migration.md) for the deployment evidence and full-population validation limits.


Read [the deployment review](../../planning/archive/reviews/ingestion-implementation-review-20261006.md)
and [the ingestion runbook](../../planning/runbooks/ingestion-runbook.md). This separate stack
adds the cloud path without altering the earlier verified batch workflow.

Terraform variables are generated by `scripts/aws/prepare-ingestion.py`. State is in the [shared S3 backend](../tfstate-bootstrap/README.md). Keep plan JSON
and private inputs outside OneDrive under `%LOCALAPPDATA%/IS459-G3`. The deployment
helper initializes shared state and requires `-Execute` to apply.

For an existing deployment, use the guarded `scripts/aws/update-ingestion.ps1` helper
with a newly prepared artifact directory and pinned worker image. The
[optimisation implementation](../../planning/runbooks/pipeline-optimisation-implementation.md)
documents parallel verification/scoring/corridors, 15-second bounded SageMaker
status checks, stage reuse, reduced export inputs and run-owned failure cleanup.
The update preserves predecessor artifact objects. Their old Terraform addresses
are removed without AWS deletion; include those historical prefixes in final S3
cleanup. Current deployment artifacts use `aws_s3_object.deployment_artifact`.

`workflow.asl.json` is generated from the reviewable `build-workflow.py`. Regenerate
it with `python infra/ingestion/build-workflow.py` after changes. AWS definition
validation is available through `scripts/ingestion/check-ingestion.py`, which is read-only.

Runtime catalog tables and S3 run outputs are not Terraform-managed resources and
need separately reviewed cleanup. This stack installs a terminal-status cleanup
trigger for failed/aborted/timed-out executions, but no ingestion schedule. Caller
IAM policy output is informational; attaching it is a separate reviewed action.
