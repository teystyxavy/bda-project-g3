# Historical milestones

`reviews/` preserves prior local analysis, infrastructure reviews, deployment
preparation and verification notes. `architecture-proposal/` preserves the initial
editable proposal diagrams. These files explain how the project evolved; use
the [documentation index](../README.md) for the current workflow.

Historical run IDs, timings and local output paths remain valid as dated evidence.
They do not imply that every older command or release is the current default.
