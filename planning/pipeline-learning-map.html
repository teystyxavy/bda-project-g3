The four Step Functions workflows
is459-g3-cloud-ingestDefault entry: acquire inputs, then start and wait for the main batch.
is459-g3-ingestMain batch: curate → parallel checks/scoring/analysis → export → publish.
is459-g3-raw-triggerOptional entry: EventBridge responds to an S3 trigger marker and starts the batch once.
is459-g3-reviewed-batchEarlier retained workflow: score and analyse already curated data.
Optional streaming demo — separate from the batch

CSV replay → Kinesis → Lambda → DynamoDB + S3

Replay sends transactions one by one. Lambda uses account history and the saved model to score them. DynamoDB keeps account state and results; S3 keeps an audit trail.

Parked: the Kinesis stream was deleted to stop shard charges. This demo does not feed the current dashboard, and the batch answers both business questions without it. SNS reports processing failures; transaction alerts are outside this demo’s verified scope.
