          Where the build differs from the proposal slides
          
    
            
      
          • EventBridge is an opt-in upload routeThe S3 marker trigger passed its 7 October smoke test and duplicate check. The default launcher still uses cloud acquisition. Nothing runs on a recurring schedule.
            • 
      
          • Training creates a candidateScoring uses the frozen model shipped with the deployment. Training never promotes a model automatically.
            • 
      
          • The catalog uses an explicit schemaThe build registers tables with date partition projection rather than using a Glue crawler.
            • 
      
          • FX uses two providersFrankfurter covers 11 currencies; Yahoo Finance supplies Bitcoin, the ruble and Saudi riyal rates.
            • 
      
          • Budget alerts do not cap spendingThe project has a USD 10 monthly warning against the USD 250 course allowance. Old bill and forecast figures are historical, not a current quote.
            • 
      
          • Streaming is parkedThe stream and mapping were removed after the bounded replay. No incoming streaming dashboard or transaction-risk SNS alerts are implemented.
            • 
      
          • The pipeline is not incrementalNormal full runs cover the historical dataset; smoke runs use a bounded subset. Caching reuses unchanged work rather than processing daily additions.
