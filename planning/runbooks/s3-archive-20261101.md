Each file is stored at `buckets/<original-bucket>/<original-key>`. Every source
file was hashed with SHA-256 and compared with the destination's S3-generated
SHA-256 checksum and content length. Destination versions were checked again
before deleting sources. Source inventories were compared before copying and
again before deletion; no changed objects or unfinished multipart uploads were
accepted. All source objects were current, unversioned, S3 Standard objects;
there were no historical versions or delete markers to preserve.

The six original buckets were then emptied and deleted. The old lab Glue job
was deleted only after its definition had been archived. No active job runs,
job triggers, EMR clusters, scheduled/running crawlers, CloudFront origins,
Athena workgroup outputs, Lambda configurations, S3 logging destinations or
CloudTrail trails were found to depend on these buckets, except the explicitly
retired lab job's script reference. Checks covered the sources' US East and
Singapore regions and the account's CloudFront distributions.

Archived bucket configurations, inventories, dependency snapshots, the old job
definition, copy receipts and completion record are stored privately under
`_archive/20261101/`. Object contents, metadata and tags were copied; original
bucket public permissions were not applied to the archive.

## Infrastructure, access and cost

[`infra/archive/`](../../infra/archive/README.md) manages six archive resources:
the bucket, public-access block, ownership controls, encryption, versioning and
HTTPS-only policy. The applied Terraform plan added only these six resources;
its post-apply plan reported no changes. Terraform manages the bucket settings;
S3 APIs performed the copying, verification and removal of the old buckets.

The archive has its own `archive/terraform.tfstate` key in the existing shared
backend. The setup helper recognizes `archive`; the shared input inventory and
empty input file were published and read back. There are now 13 state keys,
including the two retired predecessor stacks. Private migration scripts and
detailed local receipts are gitignored under `output/s3-archive-20261101/`.

Data remains in S3 Standard for immediate access, with no automatic expiration
or Glacier transition. Consolidation reduces bucket clutter, not the amount of
data retained. Normal storage/request charges and one-time cross-region copy
charges apply; no measured cost reduction is claimed. See
[S3 pricing](https://aws.amazon.com/s3/pricing/) and
[AWS copying guidance](https://docs.aws.amazon.com/AmazonS3/latest/userguide/copy-object.html).
No AML processing or model-training jobs were started by this migration.
