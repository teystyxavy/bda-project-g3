Sources, definitions and limitations

Amounts are USD-equivalent historical valuations. Treasury uses same-day FX; AML uses prior-calendar-day FX. FX inputs use Frankfurter and Yahoo Finance for coverage gaps. Dataset timezone and publication timing remain unverified.

BQ1 uses complete outgoing histories of hash-selected senders (about 5%); BQ2 covers all transactions. Training is Sep 1–6, validation Sep 7–8, test Sep 9–10. Sep 11–18 is a sparse, label-enriched tail. Rolling history before Sep 1 is unavailable.

Rule: ACH +50; amount above training payment-format P99 +20; prior-hour count >10 or prior-day distinct counterparties >15 adds +30. Labels evaluate results and never determine scores. Average precision groups tied scores; top-100 metrics depend on the documented tie policy.

Model: XGBoost trained on Sep 1–6; category mappings and class weights use training only. Validation selects the frozen model. Weighted scores are uncalibrated. Evidence shows the three largest signed TreeSHAP contributions to the model margin, not causal proof. No model flag threshold is defined. Earlier whole-dataset EDA makes these results exploratory; test data is not used for further tuning.

Queue identifiers refer to synthetic accounts. Labels are omitted from the queue. This static snapshot is not a live alerting system.
